# Task specs

Versioned task specifications live under this directory. Each implementation
task must have a scope, non-goals, affected files, acceptance criteria, and
test plan before code changes begin.

`progress.md` is temporary execution state for long or interruptible tasks.
Durable decisions and handoff information must be promoted into the spec or
public project documentation before wrap-up.

The current task is [`bootstrap/spec.md`](bootstrap/spec.md).
